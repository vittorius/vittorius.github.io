## Projects
Rust Zed Settings Sync: a settings sync extension for Zed editor that monitors changes in user settings files and syncs then into a Github Gist
Rust Lox interpreter: a Lox interpreter written in Rust while following the "Build your own Interpreter" Challenge at CodeCrafters that represents the interpreter part of the Crafting Interpreters book by Robert Nystrom.
Rust "Build your own Claude Code" Challenge: a simple Claude Code-like harness for an LLM that exhibits the main features of an AI coding assistant: agent loop, using skills, running scripts within skills, etc.
