- {{ icon(name="rust", theme_aware=true) }}[Zed Settings Sync](https://github.com/vittorius/zed-settings-sync/):
  a settings sync extension for Zed editor that monitors changes in user
  settings files and syncs then into a Github Gist
- {{ icon(name="rust", theme_aware=true) }}[Lox interpreter](https://github.com/vittorius/lox-interpreter-rs/):
  a Lox interpreter written in Rust while following the
  ["Build your own Interpreter" Challenge](https://app.codecrafters.io/courses/interpreter/overview)
  at CodeCrafters that represents the interpreter part of the
  [Crafting Interpreters](https://craftinginterpreters.com/) book by Robert
  Nystrom.
- {{ icon(name="rust", theme_aware=true) }}["Build your own Claude Code" Challenge](https://github.com/vittorius/codecrafters-claude-code-rust):
  a simple Claude Code-like harness for an LLM that exhibits the main features
  of an AI coding assistant: agent loop, using skills, running scripts within
  skills, etc.
